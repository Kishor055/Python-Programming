 ## 📌 About This Repository

 Welcome to the **Python Programming — Theory, Code & Output** repository.

 This repository is designed as a structured and practical resource for learning Python programming from **absolute beginner to advanced level**.

 Each topic focuses on understanding the concept first and then applying it through practical Python programs.

 The learning approach is simple:

```
📖 Theory
   ↓
💻 Syntax
   ↓
🧪 Example
   ↓
▶️ Output
   ↓
🧠 Explanation
   ↓
📝 Practice
   ↓
🚀 Project
```

 The goal is not only to teach **how to write Python code**, but also to explain **why the code works**.

 # 💻 Code + Output Approach

 One of the main goals of this repository is to show **actual code together with its expected output**.

 For example:

 ### Python Code

```
name = "Python"
version = 3

print("Language:", name)
print("Version:", version)
```

 ### Output

```
Language: Python
Version: 3
```

 ### Explanation

 - `name` stores a string value.
- `version` stores an integer.
- `print()` displays the values.
- Python determines the data type automatically.

 This format makes the repository useful for both **learning and quick revision**.

 # ▶️ Running the Programs

 Clone the repository:

```
git clone <your-repository-url>
```

 Navigate into the project:

```
cd python-programming
```

 Run a Python file:

```
python 01-Basics/01_hello_world.py
```

 On systems where `python3` is required:

```
python3 01-Basics/01_hello_world.py
```
